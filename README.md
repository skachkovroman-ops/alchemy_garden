# Alchemy Garden — Уютная 2D-игра для Android

Уютная игра в стиле *Cozy Grove* на Kotlin и Jetpack Compose: выращивай растения в оранжерее, вари припасы в лаборатории, отправляйся в экспедиции по острову и пробуждай духов-помощников.

## Сборка APK через GitHub Actions
1. Загрузи все файлы из архива в корень нового репозитория на GitHub.
2. Перейди во вкладку **Actions** в репозитории и дождись завершения workflow `Build Android APK` (или запусти его вручную через кнопку `Run workflow`).
3. Скачай готовый файл `alchemy-garden-debug` из раздела **Artifacts** внизу страницы сборки.
